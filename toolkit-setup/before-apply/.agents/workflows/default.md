# Default workflow

1. Establish the outcome and constraints. Read applicable project guidance and
   relevant code or artifacts. Check existing work before choosing an approach.
2. For complex work, give a short plan. Resolve routine choices using context;
   ask about consequential uncertainty and continue independent work meanwhile.
3. Implement the authorized scope, using a relevant skill when it adds value.
   Keep changes focused; adapt the plan when evidence changes the approach.
4. Run proportionate checks and inspect the resulting changes. Distinguish static
   checks from runtime evidence and identify checks that could not run.
5. Report the outcome, validation, and remaining limitations concisely. If blocked,
   identify the concrete missing input or capability and the work completed.

An explanation or review request stays within that scope. Keep project-specific
plans and session context outside the portable folder.
